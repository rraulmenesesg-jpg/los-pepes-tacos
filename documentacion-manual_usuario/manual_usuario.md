# Manual de Usuario
## Menú Digital — Taquería Los Pepes

**Versión:** 1.0  
**Tipo de usuario:** Cliente  
**Acceso:** Código QR o enlace web  
**Sitio:** https://los-pepes-tacos.netlify.app/

---

### 1. Introducción

El menú digital de Taquería Los Pepes permite consultar los productos y precios del establecimiento desde un teléfono móvil, tablet o computadora.

También proporciona acceso a la información de pago mediante transferencia y un enlace directo para contactar al negocio por WhatsApp.

### 2. Cómo acceder al menú

1. Abrir la cámara del teléfono.
2. Apuntar al código QR disponible en el establecimiento.
3. Seleccionar la notificación o enlace que aparece en pantalla.
4. Esperar a que el navegador abra el menú digital.

También se puede ingresar directamente mediante:

https://los-pepes-tacos.netlify.app/

### 3. Consultar productos y precios

Al ingresar al sitio:

1. Localizar las categorías disponibles.
2. Consultar los productos de cada categoría.
3. Revisar el precio mostrado junto a cada producto.
4. Consultar las notas adicionales cuando estén disponibles.

Las categorías disponibles son:
- Tacos.
- Burritos.
- Bebidas.

Los precios publicados corresponden a la información proporcionada por el establecimiento.

### 4. Consultar información de pago

En la sección de pago se muestra la información necesaria para realizar una transferencia bancaria.

Antes de realizar cualquier operación:
1. Revisar cuidadosamente los datos mostrados.
2. Confirmar que corresponden al destinatario esperado.
3. Utilizar la información indicada en el sitio para realizar la transferencia desde la aplicación bancaria correspondiente.

### 5. Copiar la referencia bancaria

El sitio incluye un botón para copiar la referencia bancaria.

Pasos:
1. Localizar la sección de pago.
2. Seleccionar el botón de copiado.
3. Esperar el mensaje de confirmación.
4. Abrir la aplicación bancaria.
5. Pegar la referencia en el campo correspondiente.
6. Revisar los datos antes de confirmar la transferencia.

**Importante:** copiar la referencia no realiza una transferencia ni confirma un pago.

### 6. Contactar por WhatsApp

Para contactar al establecimiento:

1. Localizar la sección de WhatsApp.
2. Seleccionar el enlace o botón correspondiente.
3. Esperar a que se abra WhatsApp o WhatsApp Web.
4. Revisar el mensaje predefinido.
5. Enviar el mensaje si se desea continuar la comunicación.

La disponibilidad de WhatsApp depende de la conexión a internet y del servicio externo.

### 7. Problemas frecuentes

| Problema | Posible solución |
|---|---|
| El QR no abre el sitio | Revisar la conexión a internet e intentar escanear nuevamente. |
| El menú no muestra productos | Recargar la página e intentar nuevamente. |
| No se copia la referencia | Revisar los permisos del navegador o copiar la información disponible manualmente. |
| WhatsApp no abre | Comprobar que la aplicación esté instalada o utilizar WhatsApp Web. |
| La página no carga | Verificar la conexión a internet y volver a intentarlo. |

### 8. Recomendaciones

- Verificar los precios antes de realizar un pedido.
- Revisar los datos bancarios antes de transferir.
- Confirmar que la referencia se haya copiado correctamente.
- No compartir información bancaria personal.
- Utilizar WhatsApp para continuar la comunicación con el establecimiento.

### 9. Alcance del menú digital

El menú digital es una herramienta informativa y de contacto.

Actualmente no permite:
- Realizar pedidos mediante un carrito.
- Pagar directamente desde el sitio.
- Confirmar automáticamente transferencias.
- Consultar el estado de un pedido.
- Programar entregas a domicilio.
